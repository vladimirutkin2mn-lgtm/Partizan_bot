Need help with Partizan?

Partizan is still in beta. The current support entry point is the product's GitHub issue tracker so every product problem can be tied to a reproducible fix.

Last updated · 28 August 2026

Product, account or billing question

Open a support issue with the smallest amount of information needed to reproduce the problem. Do not include passwords, API keys, provider tokens, payment-card information, customer PII or other secrets.

Open support issue ↗Open workspace

Security issue

Do not put vulnerability details into a normal public issue. Use the private reporting guidance on the Security page.

Security reporting →

Privacy or deletion request

Open a minimal support issue requesting private follow-up. Do not put the personal data you want removed into the public issue itself.

What to include

  • which screen or action failed;
  • the approximate time of the problem;
  • the visible error message, if any;
  • whether the issue concerns research, account access, billing, a channel connection or measurement.

Screenshots are useful only after removing credentials and private customer data.
