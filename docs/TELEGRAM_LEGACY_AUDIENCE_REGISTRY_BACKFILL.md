# Telegram: перенос исторических сообществ из старого поиска

18 октября 2026 года живой аудит FemDom обнаружил десять исторических
Telegram-записей, соответствующих девяти уникальным публичным
сообществам. Все находились в `audience_distribution_map`, а
`telegram_community_registry` для FemDom был пуст.

Новый Discovery не должен покупать или искать заново те же группы,
которые уже были найдены ранее.

## Поведение

При обычном разрешённом Telegram Discovery движок теперь сначала
читает сохранённую карту аудиторий продукта и переносит отсутствующие
публичные `@handle` в канонический реестр через
`stage_legacy_telegram_communities`.

- Максимум 50 переносимых публичных сообществ за один запуск.
- Приватные приглашения, боты, другие платформы и некорректные адреса
  не переносятся.
- Повторный запуск не изменяет уже существующее подтверждённое
  состояние сообщества и не создаёт дубликатов.
- При первом переносе глобальный Telegram-поиск пропускается:
  сначала проверяются уже найденные группы.
- Сохранённые старые оценки релевантности и прежние статусы READY
  не считаются свидетельством подтверждения аудитории или права писать.

Новая запись имеет `community_fit_pass=false`,
`native_research_status=UNVERIFIED`,
`actionability=RESEARCH_ONLY` и не содержит цели для отправки.
Лишь существующая нативная проверка Telethon может подтвердить
пригодность сообщества. Непроверенные наследованные записи
исключены из финальной выдачи возможностей до такого подтверждения.

## Чего эта миграция не делает

Она **не** отправляет сообщения, не вступает в сообщества, не меняет
профиль, не назначает право публикации, не обходит DEBUG_REVIEW и не
выполняет платные веб-запросы. Она не превращает старую оценку группы
в доказательство, что последнее сообщение актуально и соответствует
теме продукта.

Отдельный пробел, выявленный живым аудитом: выбор самого нового
поста может оказаться тематически ошибочным. Его необходимо исправлять
в слое выбора **конкретной публикации**, а не повышением старого
балла группы.

## Регрессионные проверки

Проверяются перенос старых публичных ссылок, отсутствие дубликатов,
неизменность подтверждённого реестра, исключение приватных приглашений
и ботов, сохранение статуса RESEARCH_ONLY и отсутствие нового
глобального поиска/платного веб-поиска при первой миграции.
