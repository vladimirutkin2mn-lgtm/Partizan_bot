# FemDom: восстановление прежних Telegram-находок без нового поиска

## Причина

После проверки PR #545 основной реестр содержал девять публичных сообществ. Старые оплаченные результаты могли оставаться в других хранилищах. Сквозная проверка подтвердила, что четыре действующих семантических оценки `DIRECT` находились в кеше, а основной реестр помечал подтверждёнными только два сообщества (одно из них имело своё прежнее подтверждение без текущей оценки в кеше). После сверки ожидаются пять подтверждённых аудиторий.

## Доказанные источники восстановления

1. `telegram_community_registry` + `audience_distribution_map`: девять уже известных публичных сообществ.
2. `ops/femdom/live_opportunities_2026-10-08.json`: три просроченных сообщения из двух сообществ, `bizarre_afisha` уже есть, а `freepeopleschedule` отсутствовал. Восстанавливается **сообщество**, а не устаревший пост.
3. `customer_live_opportunities` выбранного FemDom-проекта: ранее сохранённые публичные Telegram-ссылки могут содержать и другие сообщества, потерянные при обновлениях сводной карты аудитории. Сканируется не больше 250 привязанных к этому продукту записей, и за один запуск добавляется не больше 40 новых уникальных публичных идентификаторов; результаты не из другого проекта. Фактическое число становится известно только после просмотра рабочей базы.

Никакие старые оценки релевантности, флаги `READY`, разрешения на публикацию и целевые ссылки не восстанавливаются. Новые строки имеют `native_research_status=UNVERIFIED`, `actionability=RESEARCH_ONLY`, `audience_fit.confirmed=false`; прежние подтверждения в существующих строках не заменяются.

## Запуск

`python -m app.femdom_archived_community_recovery --product-id 52d7e59e-5ac5-4363-b829-c93e33e48272` — безопасный просмотр без записи.

Флаг `--commit` синхронизирует действующие проверенные `DIRECT`-оценки из кеша и добавляет отсутствующие исследовательские идентификаторы из сохранённых источников, но не вызывает Telegram, глобальный поиск или модель. Операция идемпотентна.

Workflow `.github/workflows/femdom-archive-cache-migration-oneoff.yml` запускается **один раз по изменению только этого файла в main**, ждёт соответствующего развёрнутого SHA и выполняет просмотр, затем подтверждённую миграцию, затем ограниченный сквозной эксперимент. Последняя часть читает по одному новейшему посту максимум из 20 ранее найденных сообществ и делает максимум 8 вызовов LLM по промпту v11. Она формирует только закрытые черновики, не публикует, не вступает в чаты и не меняет профиль.

## Ограничения

Восстановление большого списка не гарантировано: значительная часть прежних платных поисковых выдач могла никогда не сохраняться в постоянном хранилище. Рабочая очередь и исходный архив — дополнительные доказуемые источники, но не повод утверждать, что найдены все исторические кандидаты. Если после миграции их по-прежнему мало, следующий этап — аудит сохранившихся артефактов старых GitHub Actions и журналов исследования, а не повторный поиск.

Контроль успешности: фактические `registry_before/after`, `confirmed_before/after`, число новых исследовательских сообществ, наличие свежего последнего поста и доступной поверхности ответа. Право публикации остаётся отдельной независимой проверкой; текущие Telegram-комментарии разрешаются только после пользовательского «публикуй».
