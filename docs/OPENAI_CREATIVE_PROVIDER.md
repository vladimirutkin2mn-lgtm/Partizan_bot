# OpenAI creative provider for Meta

Partizan can generate action-level paid image creatives for Instagram/Meta with OpenAI and expose the generated image through its own public read-only creative endpoint.

## Enable

Set all of the following in the production environment:

- `CREATIVE_PROVIDER=openai`
- `OPENAI_API_KEY=<secret>`
- `PARTIZAN_PUBLIC_BASE_URL=https://<public Partizan origin>`

Optional:

- `CREATIVE_IMAGE_MODEL=gpt-image-2`
- `CREATIVE_IMAGE_QUALITY=medium` (`low`, `medium`, or `high`)

The default remains `CREATIVE_PROVIDER=unavailable`, so creative generation never creates API cost unless explicitly enabled.

## Lifecycle

1. The autonomous paid worker prepares the DistributionAction and PaidCampaignSpec.
2. CreativeGenerationService builds/reuses the deterministic CreativeBrief.
3. The OpenAI provider generates a 1024x1536 PNG for Instagram/Meta.
4. Image bytes are stored restart-safely in the existing RuntimeStateStore (Postgres when `RUNTIME_STORAGE=database`).
5. A READY CreativeAsset receives a public URL at `/v1/public/creative-blobs/{id}`.
6. The creative-aware Meta execution adapter uses that action-level URL while creating the existing PAUSED campaign/ad-set/creative/ad stack.
7. Exact-budget paid activation remains a separate Growth Mandate authorization step.

Generation never activates spend and never mutates Meta campaign status.

## Safety and failure behavior

- Missing `OPENAI_API_KEY` or `PARTIZAN_PUBLIC_BASE_URL` returns `UNAVAILABLE` and creates no provider objects.
- The provider currently supports Instagram/Meta IMAGE briefs only. TikTok VIDEO remains unavailable until a real video generation + TikTok upload path exists.
- Generated bytes are limited to 12 MiB and image PNG/JPEG/WebP MIME types.
- Stored blobs include SHA-256 integrity metadata and are verified on read.
- API keys and provider credentials are never copied into CreativeAsset provenance or public responses.
- The public endpoint intentionally has no operator authentication because Meta must be able to fetch the image. Blob IDs are unguessable UUIDs; generated paid creatives should therefore be treated as public campaign assets.
